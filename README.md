## 🙋 先说清楚：这东西是干嘛的

如果你遇到过下面这种情况，那它就是给你做的：

> 在读秀 / 超星上弄到一本书，下载下来是个**压缩包**，解开之后是一堆 `.pdg`、
> `.uvz` 之类**打不开的文件**，或者几百张散着的页图 ——
> 想看还得一页一页点，也不能搜索、不能复制、不能打印。

**CathayPDG 就是干这一件事：把这一堆东西，合成一个正常的、能翻能看的 PDF。**

它还会顺手做两件事：

- 自动**判断这本书是横排还是竖排**，成品分两个文件夹放好（古籍大多是竖排，横排/竖排用不同软件 OCR 效果差很多）
- 自动**记一份转换报告**（哪些成了、哪些卡住了、卡在哪）

整个过程：**不用装任何东西、不用联网、不会动你的原件。**

## ⚡ 30 秒上手（只看这一节就够用了）

**第 1 步 · 打开**
双击 `CathayPDG 超星PDG批量转换工具 0.1.9.exe`，一个窗口就出来了。

**第 2 步 · 把东西丢进去**
两种办法，随便哪个：

- 点「**选文件…**」或「**选文件夹…**」（可以一次选好几个）
- 或者直接把压缩包 / 文件夹**拖进这个窗口**

> 「输出目录」**不用管** —— 拖东西进来它也不会自动填。**空着 = 成品直接放回原处**
> （就在你要转换的那些文件旁边，再按横排 / 竖排分好柜）。想另放别处再点「选择…」，
> 点旁边的「**清空**」就回到"放回原处"。

**第 3 步 · 点「▶ 开始转换」**

转一本几十秒很正常。怎么知道它在动？看窗口中间那行绿字：

```
⠹ 正在处理 [2/5] 书名 · Pdg2Pic 正在转 · 已用 38 秒
```

旁边还有一条一直在跑的小进度条，下面的日志每 15 秒也会报一次「还在转」。
别急着关 —— 它没卡。

转完会自动生成文件夹：

```
横排\          ← 判定为横排的书，PDF 在这儿
竖排\          ← 判定为竖排的书（古籍常见），PDF 在这儿
横竖待识别\    ← 书已经转好了，但排向没能判出来（很少见）
```

> 💡 想要整本书一个 PDF、还是每章一个 PDF？**默认整本一个**，这是绝大多数情况想要的。

## 🎒 什么都不用装

很多人怕「装软件」这一步。**这次真的不用 —— 双击就能跑。**

| 它需要的 | 怎么办 |
|---|---|
| Python 运行环境 | ⬛ 已经封进 exe 里了 |
| 看图 / 写 PDF / 解密码 的库 | ⬛ 已经封进 exe 里了 |
| 解 `.7z` / `.rar` 的引擎（7-Zip） | ⬛ 随包带着，在 `程序组件\7-Zip\` |
| 解开加密页的引擎（Pdg2Pic） | ⬛ 随包带着，在 `程序组件\Pdg2Pic\` |
| 试压缩包密码的「密码本」 | ⬛ 随包带着，308 条常见密码 |

> ⚠️ **千万别把 exe 单独拷走。**  exe 本身是单文件没错，但**两个引擎是外面的文件夹**，
> 只拎走 exe 的话，`.7z` / `.rar` 和加密页就转不了了。**整个文件夹一起拷。**
>
> 不确定缺不缺东西？窗口上有个「**环境体检**」按钮，点一下会列出还差什么。

## 🤔 常见问题

**Q：什么是 PDG？我为什么要转它？**
A：PDG 是超星 / 读秀自己定的一种电子书格式，本质上是一页一页的图片，但它**不是普通看图软件能直接翻的**。
转出来的 PDF 才是人人都能打开、能打印、能在 iPad / 手机上看的通用格式。

**Q：一本要转多久？**
A：普通的几分钟以内。遇到「加密特别狠」的那种老书会慢一些 ——
它得交给一个专门的引擎（Pdg2Pic）处理，一本 200–350 页大约 15–20 秒。
这段时间它在旁边跑，**不抢你的鼠标键盘**，你可以照常干别的。

**Q：好几本书能一次搞定吗？**
A：能，而且推荐这么做。一次把几十上百个压缩包丢进去，它排队转，中途可以「暂停」/「停止」。

**Q：有一本失败了会卡住整批吗？**
A：不会。单本失败照常记进转换报告，剩下那些继续转。

**Q：文件名是全中文的压缩包，解开之后是乱码怎么办？**
A：v0.1.6 已经自动修好了。它会自动判断这个包用的是哪种中文编码（大陆多半 GBK、港澳台多半 Big5）。
**以前版本转坏的，用新版再跑一次就能修回来。**

**Q：`.7z` / `.rar` 解不开？**
A：包里自带解压引擎了，不用你自己装 7-Zip。如果报错说「没找到可用的解压引擎」，
多半是你只把 exe 拷出来了 —— 把 `程序组件\` 一起拷过来，或者直接下便携包。

**Q：换台电脑怎么办？**
A：整个文件夹拷过去就能用。建议把设置里的「Pdg2Pic 路径」**留空**，
这样它会每次按 exe 所在的位置自动去找，挪过目录也不会失效。

**Q：看不懂那句报错怎么办？**
A：常见的就这三类，报告里都写明白了：
- `没找到可用的解压引擎…` → 把 `程序组件\` 整个拷过来（或重下便携包）
- `Pdg2Pic.exe 找不到：…` → 同上
- `解压失败（密码本未命中…）` → 这个包的密码没试出来。往 `程序组件\config\passwords.txt` 里加一行再跑

**Q：它会动我的原件吗？**
A：不会。原始压缩包完好无损；成功的原件默认移进 `已处理\`（你也可以关掉归档）。
全程**不联网、不用 AI**。

## 🛠 进阶（普通用户可以跳过）

### 界面上那几个选项是啥

| 选项 | 勾上会怎样 |
|---|---|
| **处理完归档** | 成功的原件+中间产物进 `已处理\`，失败的进 `处理失败\`（默认勾） |
| **强制重转** | 已经有同名 PDF 也重新转一遍（默认不勾，会跳过） |
| **保留解压目录** | 保留解压出来的中间文件夹，方便排查（默认不勾，转完会清掉） |

### 命令行批量跑

```bat
CathayPDG.exe --cli D:\我的书库        :: 转整个目录
CathayPDG.exe --selftest               :: 自检，看环境全不全
gui.py --check-deps                    :: 只做依赖体检
```

### 源码模式

整个包里已经塞好了一份便携 Python（`程序组件\runtime\`），不用你另外装：

- 双击 `启动.bat` —— 自动用那份便携 Python 跑源码
- 想用自己的 Python：`安装依赖.bat`（就是 `pip install -r requirements.txt`）
- 体检：双击 `pdg_deps.py`，或 `python pdg_deps.py`

### 技术细节

- **页序**不是按文件名排的：`cov001 → bok001 → leg001 → fow001 → !00001 → 000001… → cov002`
  （封面→书名页→版权页→前言→目录→正文→封底），与 Pdg2Pic 成品逐页指纹比对验证过
- **清晰度**：源扫描件本身就是 300 DPI（常见 2008×3000 px）。排成 A4 后有效分辨率 ≥200 DPI
  就**原样嵌入、零重编码**；只有不足 200 DPI 才放大（上限 5×）
- **页类型判断**：`HH` 头 + 第 16 字节（0x0F）判断编码类；`00H` 未加密可直接解，
  `AAH` / `AxH` / `6xH` 必须交厂商控件（Pdg2Pic）
- **中间产物**（解压出来的页、临时 PDF）默认转完清掉；勾「保留解压目录」可留下排查
- 依赖清单：`pillow` / `pymupdf` / `pyzipper` / `pycryptodome`（可选：`tkinterdnd2`）

## 📝 更新日志

### v0.1.9（2026-10-04）

**🐛 修好「目录名叫『横排』就什么都扫不到」的坑**

- 程序转完会自己建 `横排 / 竖排 / 横竖待识别 / 已处理 / 处理失败` 这几个归档文件夹。
  为了不重复处理，扫描时本来会跳过叫这些名字的**子目录**
- 但如果你**直接把「横排」这个文件夹当输入拖进去**，旧版连它一起跳过了 ——
  结果就是「共 0 项、什么都没干」，看上去像莫名其妙失败
- 现在：**你明确指定的输入目录永远处理**，哪怕它正好叫「横排」；
  它下面的归档子目录照旧跳过（那才是程序自己造的）
- 另外：如果一个都没扫到，日志会**直接说清原因**（能处理什么、当前目录是哪个），
  不再沉默地给你一个 0

### v0.1.8（2026-10-04）

**🆕 转完不再弹窗抢焦点 —— 结果安安静静放在窗口里**

- 以前不管你在写东西还是看网页，「转换完毕」的框会直接跳到最前面，把你的输入位置顶掉。

  结果写在状态行和日志里，**你切回窗口才看到**
- 有失败的书也不弹框了：改成**日志里逐本列出失败书名和原因**，状态栏标红

- 出错时同理：不再弹错误框，只写日志 + 状态栏红字 + 任务栏闪

**🆕 「输出目录」不再自己填东西**

- 以前拖一个文件夹进来，程序会顺手把同一个路径填进「输出目录」。很多人因此以为「必须填」
  或者「成品会另存一份」——现在**拖进来它还是空的**
- **空着 = 成品直接放回原处**（就在你转的那些文件旁边，再按横排 / 竖排分好柜）

**🆕 换台干干净净的电脑也能直接用 —— 什么都不用装**
